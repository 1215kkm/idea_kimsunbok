## 권장 (머지 후 가능)

- **자격 미달일 때 골드 2개** (`page.tsx:228 입금 링크`, `:334 캠페인 만들기`) — 한 화면 한 목표. 미달이면 입금 링크가 골드, 캠페인 만들기는 아웃라인(네이비 보더)으로 내리고 자격 생기면 반대로.
- **미리보기 안의 골드 CTA** (`CreateForm:308`) 는 진짜 버튼처럼 보여 눌러보게 됨 → `aria-hidden` + `pointer-events-none`, 살짝 축소(`scale-95 opacity-90`) 로 "샘플" 느낌.
- **누르는 맛** (원칙 7): 타일·칩·CTA 에 `active:scale-[0.98]` 없음 (입금 페이지 CTA 는 `active:scale-95` 있음). `tileCls` 한 곳에 넣으면 금액·인원·채널·템플릿 전부 해결. 바닥 시트 모달(`CreateForm:345`, `Detail:247`) 진입 애니메이션·Esc 닫기 없음 — 관리자 `Modal.tsx` 패턴 그대로.
- **터치 타겟**: 타일 `py-2.5` + 12px 글자 ≈ 36px 높이 < 44. `py-3` 으로. 헤더 `←` 텍스트 링크(`page:266`) 는 44×44 박스로.
- **템플릿 카드 3개** (`CreateForm:249-266`) — `line-clamp-2` 톤 설명이 좁은 폭에서 잘림. 이름만 두고 톤은 선택된 카드 아래 한 줄로.
- **취소된 캠페인 라벨**: 목록 "취소" 회색 ✓ 인데 상세 잔여 예산 칸이 "반환됨" 으로 바뀌는 건 좋음. 다만 `rejected + owner_cancelled` 인 경우 거절 사유 박스는 숨기지만 `statusBadge` 만 보고 "취소했다" 를 알 수 있게 상세 요약에 "내가 취소함 · {날짜}" 한 줄 추가.
- 정직줄 `honestLine("")` — 생성 단계엔 코드가 아직 없어 끝이 `가입 코드 ` 로 비어 보일 가능성. `reward-copy-templates` 안 읽었으니 강개발 확인만: 비면 "가입 코드는 제출 후 발급" 으로.
